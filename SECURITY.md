# Security and safety reports

Bedside Drug Guide is a single static page. It has no server and no accounts, and it doesn't send anything anywhere. Stars, notes and custom entries stay in the browser on the device where they were made.

## Report a security problem privately

Use [Report a vulnerability](https://github.com/Darkness-Alone/Nurses-Drug-Guide/security/advisories/new) on this repository's Security tab. Only you and the maintainers can see the report. Please don't open a public issue for a security problem.

For example, report:

- text in a backup file, custom entry, note, search or link that runs as code in the page
- a way for the page to load code from another site, or to send saved data to one

Include your browser and device, the steps to reproduce the problem, and if you can, a sample file or link that shows it.

## Report a dosing or content error

A wrong dose, route, rate or interaction is a patient-safety problem, so report it even if you aren't sure. [Open an issue](https://github.com/Darkness-Alone/Nurses-Drug-Guide/issues/new) with:

- the drug and the section, for example "heparin, Dosing"
- what the guide says and what it should say
- a source, such as the prescribing information on [DailyMed](https://dailymed.nlm.nih.gov/)

Never include patient information in a report.

## Supported version

Only the current page at https://darkness-alone.github.io/Nurses-Drug-Guide/ is maintained. If you use a downloaded copy, download it again to get fixes.
